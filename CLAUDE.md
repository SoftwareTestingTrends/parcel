# Parcel

Course demo app for *AI Evals Explained for Software Testers*. See README.md.

- `make test` and `make lint` must pass before any commit. Tests run offline on the mock backend.
- The "Known weaknesses" in README.md are deliberate teaching material. Don't fix them unless asked.
- Change `PROMPT_VERSION` in `src/parcel/prompts.py` whenever the system prompt text changes.
- Keep the code readable for testers who know a little Python: plain functions, comments that say why.
- All customer data is fictional and uses example.com addresses.
